# Product-Led Landing Pages

## Use when

Use for self-serve products where visitors can experience value without a sales process.

## Primary belief

> I can achieve something valuable quickly without understanding the entire product first.

## Structure

1. Output-oriented hero.
2. First-value demonstration.
3. Capability groups organized by outcome.
4. Templates, examples, or use cases.
5. Trust and friction reduction.
6. Segment routing.

## Copy rules

- Write about what the visitor can make or accomplish.
- Use transformation verbs: create, turn, remove, resize, generate, publish.
- Make the first CTA reversible.
- Use examples instead of abstract adjectives.

## Example hero

```text
What will you create today?
Turn rough ideas into polished content with simple AI-powered tools.

[Start creating]
```

## Failure modes

- Leading with a feature catalog.
- Making visitors compare plans before experiencing value.
- Calling the product easy without demonstrating the workflow.
- Using AI as the benefit instead of describing the resulting output.
