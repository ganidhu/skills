# Marketplace and Platform Landing Pages

## Use when

Use for marketplaces, multi-sided platforms, sports ecosystems, creator platforms, app ecosystems, and network-effect businesses.

## Primary belief

> There is enough activity, supply, demand, or partner quality here for participation to be worthwhile.

## Structure

1. Network value.
2. Participant groups and their individual benefits.
3. Network proof.
4. Ecosystem explanation.
5. Separate participation CTAs.

## Copy rules

- Explain the network before listing products.
- Connect scale to participant benefit.
- Make each side of the marketplace feel seen.
- Use ecosystem language only when there is real integration or distribution advantage.

## Failure modes

- Treating network size as self-explanatory.
- Speaking only to one side.
- Listing business units without explaining why they belong together.
- Asking partners to act without showing audience quality.
